# Portfolio / Shaxsiy Portfolio Sayt

Bu mening shaxsiy veb-portfolio loyiham. Saytda men o'zim haqimdagi ma'lumotlar, bajargan ishlarim va bog'lanish uchun ma'lumotlarni joylashtirganman.

## 🛠 Ishlatilgan texnologiyalar
* **HTML5** — Sahifaning tuzilishi uchun
* **CSS3** — Dizayn va bezaklar uchun
* **JavaScript (JS)** — Interaktivlik va dinamik funksiyalar uchun

## 📂 Loyiha strukturasi
portfolio/
│
├── index.html          # Asosiy sahifa
├── netlify.toml        # Netlify sozlama fayli
├── css/
│   └── style.css       # Asosiy uslublar fayli
├── js/
│   └── script.js       # Asosiy JavaScript kodi
└── images/
    └── photo.jpg       # Sayt uchun rasmlar va media fayllar
